# PC-030M20AV1 — Preserve-Goal Recovery First

Changes the direct Goal Recovery Simulator handoff so the investor is first asked whether they can add the estimated amount required today while keeping the goal target, target date, and monthly contribution unchanged. YES opens the existing canonical Coach G conversation with a diversification-aware allocation brief. NO exposes the existing second-level recovery alternatives.

No REAL/Practice portfolio, goal, contribution, Investor DNA, or broker order is changed.
