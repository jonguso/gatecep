# PC-030M20AR3 — Conversational Scenario Branching & Accommodation

Extends the unified Coach G Decision Conversation after the first portfolio-fit analysis.

Adds evidence-driven branches for:
- keep original idea;
- rotate an existing same-sector holding to accommodate the new security;
- test a smaller proposed amount using the existing Decision Lab concentration guard;
- redirect capital toward an underweight sector only when saved target evidence is available;
- compare alternatives before the investor decides.

Integrity rules:
- advisory/read-only only;
- no REAL or Practice portfolio mutation;
- no Investor DNA mutation;
- no fabricated underweight sector;
- Coach G never silently chooses which holding to reduce;
- external broker execution and later verified evidence remain the only path to REAL changes.
