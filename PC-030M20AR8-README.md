# PC-030M20AR8 — Projected Holding & Portfolio Impact Review

Adds a separate **View Projected Impact** review to REAL Trade Lab scenarios.

The review shows Current vs Projected quantity, WAP, portfolio weight, sector exposure and available cash. BUY uses the established weighted-average result when an existing holding exists; a brand-new BUY derives its initial acquisition WAP from scenario gross value plus displayed acquisition charges. SELL remains gated by the existing FIFO/cost-basis evidence and never fabricates remaining WAP or realized P/L.

The feature is advisory/read-only. It does not mutate REAL, Practice, Investor DNA, goals, or broker evidence. Broker Action Plan remains a separate handoff.
