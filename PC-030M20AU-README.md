# PC-030M20AU — Recommendation Selection → Conversation → Simulation

Recovery entry into Decision Lab is now recommendation-first instead of form-first.

The selector loads the current REAL Wealth Journey and displays the actual `recovery.scenarios` produced for the matching goal. `recommendedScenarioId` marks the recommended card. Each card preserves the planner's title, description, trade-off, feasibility and Coach G question when available.

Selecting a card starts the existing Floating Coach discussion with that recovery option as context. `Compare all options` starts a comparison discussion. `Create my own what-if` reveals the existing BUY/SELL/security/amount form.

No fixed number of recommendations is invented. If the recovery planner has no scenarios, GateCEP says so rather than creating placeholder options. The selector is advisory-only and does not change goals, Investor DNA, REAL/Practice portfolios or broker execution state.
