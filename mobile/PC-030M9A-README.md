# PC-030M9A — Profile Contribution Recovery

This increment connects the saved investor contribution plan to canonical REAL Wealth Journey projections and recovery scenarios.

- Monthly amounts are modeled as recurring monthly cash flow.
- Quarterly amounts are normalized to a monthly planning equivalent.
- One-time amounts are not treated as recurring cash flow.
- Explicit monthly contribution fields take priority over compatibility fields.
- Recovery options show the current contribution, proposed total, and additional increase.
- Practice data remains excluded and all recovery options remain advisory-only.

Run `bash scripts/verify-pc030m9a-profile-contribution-recovery.sh`.
