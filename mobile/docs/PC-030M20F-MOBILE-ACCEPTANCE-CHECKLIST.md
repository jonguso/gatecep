# GateCEP mobile acceptance checklist

Use the installed preview APK against the production Railway backend.

- Launch: approved blue GateCEP logo is visible and no startup error appears.
- Authentication: register, login, close/reopen, and logout work.
- Portfolio: valuation PDF shows the expected holdings before confirmation.
- Cash: statement PDF shows the latest broker balance and effective date.
- Orders: broker order history remains evidence; it does not create REAL fills.
- Boundaries: GateCEP trade entry remains Practice-only.
- Markets: securities, indices, watchlist, and contained scrolling work.
- Calendar/news: verified source links and daily event details open.
- Resilience: airplane mode produces a readable error and retry succeeds after reconnecting.
- Navigation: Home, Markets, Trading, Calendar, News, and Menu have no dead ends.

Record device model, Android version, APK build link, tester, result, and any screenshot for each failure.
