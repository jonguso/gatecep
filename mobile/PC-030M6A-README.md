# PC-030M6A — Focused Performance Detail Navigation

Performance remains the canonical parent and continues to load its existing REAL snapshot, historical-performance, benchmark, goal, drawdown, health, record, milestone, and snapshot contracts once.

## Mobile presentation

- The parent shows a compact performance summary and nine tappable destinations.
- Mobile destinations use a two-column grid.
- Only one selected detail is visible at a time.
- Every detail provides **Back to Performance** at the top and bottom.
- Portfolio Milestones is separated from Performance Records.
- The design does not create nine duplicate data loaders or new sources of truth.

## Destinations

1. Portfolio Value Timeline
2. Historical Performance
3. Benchmark Comparison
4. Goal Progress Intelligence
5. Performance Records
6. Portfolio Milestones
7. Portfolio Drawdown
8. Portfolio Health Trend
9. Snapshot History
