# PC-030M7A — Focused Portfolio Risk

destinations instead of presenting every analytics section in one continuous
page.

## Focused destinations

1. Coach G Risk Assessment
2. Risk Profile & Limits
3. Concentration Analysis
4. Diversification
5. Historical Risk Metrics

The overview returns to the canonical Home route. Every detail returns to the
Portfolio Risk parent. Existing REAL risk analytics, genuine-history rules,
saved risk-profile behavior, filters, and analytics-only protections are
preserved.
