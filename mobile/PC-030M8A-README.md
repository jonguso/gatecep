# PC-030M8A — Aligned Global Menu

This increment aligns GateCEP's Menu with the portfolio-first mobile architecture.

- Replaces the long flat list with four compact, collapsible groups.
- Removes the duplicated `My Journey` / `Wealth Journey` menu presentation.
- Adds direct access to Performance, Portfolio Analysis, and Portfolio Risk.
- Adds a shared authenticated Menu control to detail screens.
- Keeps Login, Register, onboarding, Menu, and the existing Home header free of duplicate controls.
- Provides explicit Back and Home navigation from Menu.
- Keeps Practice and Sandbox outside the production Menu.

Verify with:

```bash
chmod +x scripts/verify-pc030m8a-global-menu.sh
bash scripts/verify-pc030m8a-global-menu.sh
```
