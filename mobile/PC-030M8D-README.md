# PC-030M8D — Focused Rebalancing

Portfolio Rebalancing is now a compact mobile journey instead of one continuous report.

The overview shows the current recommendation state and five focused destinations:

1. Portfolio Health
2. Target Profile
3. Allocation & Drift
4. Funding Readiness
5. Recommendations

Every detail has a dedicated parent Overview control, an upper Previous control, a lower Next control, a position indicator, and scroll reset. The final step completes back to the Rebalancing overview. Existing PC-019 advisory-only calculations, target-profile updates, and no-trade protections remain unchanged.

Run `bash scripts/verify-pc030m8d-focused-rebalancing.sh`.
