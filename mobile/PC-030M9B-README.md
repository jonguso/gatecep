# PC-030M9B — Broker Evidence Identity Gate

This increment prevents broker uploads from being mixed across investors or accounts.

- One GateCEP user has one verified CDS number.
- A different filename CDS is rejected as another investor.
- Broker ID plus trading/client account identifies a specific broker account.
- Valuation and cash evidence must resolve to the same CDS and account key.
- Statement and order-history fields are available as internal cross-checks.
- Practice or demo evidence is never accepted by the REAL reconciliation boundary.

The filename suffix is used as the current broker-provided CDS convention. Duplicate download suffixes such as `(5)` are ignored.

The verifier disables the app-level Babel preset while executing its isolated contract test, making it safe on Windows Git Bash and Expo projects that enable the Expo DOM directive plugin.

Migration fix: the upload screen loads CDS from current and legacy profile stores. If none exists, the investor enters it once; a matching broker filename establishes the locked user-level CDS record.
