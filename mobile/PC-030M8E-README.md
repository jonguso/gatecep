# PC-030M8E — Sector-First Risk Concentration

Risk Concentration now follows a two-level mobile hierarchy:

1. The parent screen shows sector concentration only.
2. Tapping a sector opens the canonical REAL securities belonging to that sector.

The sector screen retains largest-sector, effective-sector, configured-limit, allocation, market-value, and limit-status evidence. The security drill-down retains allocation, value, and single-holding limit evidence. No Practice holdings or fabricated values are introduced.

Run `bash scripts/verify-pc030m8e-sector-first-risk-concentration.sh`.
