# PC-030M20AV3 — Investor Journey Consolidation

Removes Holdings and Portfolio Rebalancing from the compulsory numbered Investor Journey without deleting either capability.

Changes:
- Investor Journey becomes 6 stages.
- Portfolio Risk continues directly to Goals & Wealth Journey.
- Holdings stays available at `/holding-details` and is added to the main menu.
- Portfolio Rebalancing stays available at `/portfolio-rebalancing` and is added to the main menu.
- Journey count is derived from the canonical map instead of hard-coded `OF 8`.

Preserved:
- REAL holdings screen and services.
- Rebalancing targets, drift analysis, Coach G advisory logic, and recommendations.
- Goal Recovery Simulation custom handoff and AV2 recovery flow.
- Projected portfolio, verified fees, Broker Action Plan, and import-gated REAL updates.

No portfolio, goal, fee, execution, or reconciliation calculations are changed.
