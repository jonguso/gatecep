# PC-030M17F — Broker Account Panels

This package standardizes Broker Accounts for mobile use.

- Connected and Available broker lists now occupy one focused panel at a time.
- Both lists use the same contained internal scrolling behavior as Equities and Watchlist.
- Existing broker connection, edit, default selection, and disconnect behavior is preserved.
- Order execution is unchanged.
