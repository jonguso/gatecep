# PC-030M20AU3 — Select Recommendation → Coach G Response

M20AU3 changes recovery cards from one-click conversation launchers into explicit investor selections.

1. Investor selects a recovery card.
2. The selected card is marked `SELECTED ✓`.
3. Coach G immediately explains that exact option using only its existing recovery evidence: title, description, trade-off, feasibility, goal gap and planner question.
4. `Answer Coach G` then hands that exact selected option to the existing Floating Coach conversation.
5. The RECOMMENDED badge remains advisory and never auto-selects an option.

The old generic “What part of that recommendation…” prompt is removed when present.

No goal, Investor DNA, REAL/Practice portfolio, FIFO evidence, broker execution or Broker Action Plan state is mutated.
