\# Engineering Principles



Every engineering decision must satisfy these questions.



\---



\## 1



Does this improve Investor DNA?



\---



\## 2



Does this help Coach G become a better advisor?



\---



\## 3



Does this help investors make better long-term decisions?



\---



\## 4



Does this build trust?



\---



\## 5



Can Coach G explain this recommendation?



\---



\## 6



Does this move investors closer to their Wealth Journey?



\---



\## 7



Would we proudly recommend this feature to our own families?



If the answer is NO...



We redesign it.
