PC-030M20AV2F3 — Verified Broker Fee Schedule Management

Adds optional fee-schedule management to the existing Broker Accounts workflow.

A schedule becomes verified only when the investor explicitly confirms the values were checked against broker-published evidence and provides both an evidence source and a verification date.

The package does not seed broker rates and does not copy the hard-coded Trade screen policies into broker evidence.
Verified schedules use the existing canonical brokerAccount.feeSchedule contract and are automatically consumed by AV2F/AV2F2.
