PC-030M20AV2F2 — Fee Evidence + Residual Funding Integrity

This package does not invent or seed broker fee schedules.

It preserves feeSchedule through canonical/default broker-profile boundaries and Broker Accounts edits.
It also distinguishes gross funding remaining before unknown charges from funding remaining after verified estimated charges.
When fee evidence is absent, the preview displays Verified estimated charges = Unavailable.

Existing AV2F fee calculations remain unchanged and only use verified broker fee schedules.
