# PC-030M17A — Core investor responsive shell

This establishes the shared responsive contained-panel contract and applies it to the permanent investor navigation:

- Home: one internally scrollable active tab panel.
- Markets: one exclusive Market Results, Indices, or Watchlist panel.
- Trading: one internally scrollable active trading panel.
- Calendar: one month view with internally scrollable day-event popup.
- News: one internally scrollable active news category panel.

Forms and guided workflows continue to use normal page scrolling so inputs and actions remain accessible.

Run `bash scripts/verify-pc030m17a-core-investor-responsive-shell.sh` from `mobile`.
